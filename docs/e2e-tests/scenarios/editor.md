# Editor E2E Test Scenarios

## 개요
텍스트 에디터 핵심 기능 검증을 위한 E2E 테스트 시나리오

---

## 카테고리

### A. 기본 입력 (Basic Input)
| ID | 시나리오 | 설명 | 우선순위 |
|----|----------|------|----------|
| E-001 | 영문 입력 | 영문 텍스트 입력 후 내용 확인 | High |
| E-002 | 숫자 입력 | 숫자 입력 후 내용 확인 | High |
| E-003 | 특수문자 입력 | 특수문자(!@#$%^&*) 입력 확인 | Medium |

### B. 한글 IME 입력 (Korean IME)
| ID | 시나리오 | 설명 | 우선순위 |
|----|----------|------|----------|
| E-010 | 한글 기본 입력 | "안녕하세요" 입력 후 내용 확인 | Critical |
| E-011 | 한글 연속 입력 | 빠른 연속 입력 시 글자 깨짐 없음 | Critical |
| E-012 | 한글 중간 삽입 | 기존 텍스트 중간에 한글 삽입 | Critical |
| E-013 | 한글 + 영문 혼합 | "Hello안녕World세상" 입력 | High |
| E-014 | 한글 삭제 후 재입력 | 한글 입력 → Backspace → 재입력 | High |
| E-015 | 한글 조합 중 방향키 | 조합 중 화살표 키 → 조합 완료 확인 | Medium |

### C. 줄바꿈 및 멀티라인 (Line Break & Multiline)
| ID | 시나리오 | 설명 | 우선순위 |
|----|----------|------|----------|
| E-020 | Enter 줄바꿈 | Enter 키로 새 줄 생성 | Critical |
| E-021 | 라인 번호 동기화 | 줄 추가 시 라인 번호 증가 확인 | High |
| E-022 | 중간 줄바꿈 | 텍스트 중간에서 Enter | High |
| E-023 | 빈 줄 처리 | 연속 Enter로 빈 줄 여러 개 생성 | Medium |
| E-024 | 긴 텍스트 줄바꿈 | 자동 줄바꿈(word wrap) 확인 | Medium |

## 우선순위별 실행 순서

### Phase 1: Critical (필수)
- E-010, E-011, E-012 (한글 IME)
- E-020 (줄바꿈)
- E-060 (탭 전환)

### Phase 2: High (중요)
- E-001, E-002 (기본 입력)
- E-013, E-014 (한글 혼합)
- E-021, E-022 (멀티라인)
- E-030~E-034 (선택/편집)
- E-040~E-042, E-044 (복사/붙여넣기)
- E-050, E-051, E-053 (Undo/Redo)
- E-061, E-062 (탭 관리)
- E-070, E-071 (스크립트)
- E-080~E-082 (커서)

### Phase 3: Medium (일반)
- 나머지 시나리오
